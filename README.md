# App Finanças — MVP

Aplicação SPA (React + Vite + Tailwind) para gestão financeira pessoal — versão MVP.

Como rodar localmente:

```bash
npm install
npm run dev
```

Deploy para GitHub Pages:

1. Ajuste `base` em `vite.config.js` (feito).
2. Instale `gh-pages` e execute `npm run deploy`.
# Finanças MVP

Aplicativo SPA mobile-first para organização de finanças pessoais (MVP).

Como rodar:

1. Instale dependências:

```bash
npm install
```

2. Rode em desenvolvimento:

```bash
npm run dev
```

Notas:
- Estado é persistido via LocalStorage.
- Chat processa intenções via regex/includes conforme PRD.
